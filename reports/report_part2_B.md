### 3.2 問い・選択肢・正解・ミッション

**ステップ 1　アレイアンテナとは**

- 問い：同じ電波を出すアンテナを 2 つ、1 波長だけ離して並べる。正面（2 つから等しい距離の方向）では、電波は強め合う。では、斜め 30° の方向ではどうなる？
- 選択肢：A) 正面と同じ強さになる　B) 少し弱くなるが、0 にはならない　C) ちょうど打ち消し合って、0 になる　**← 正解**
- 理由：斜め 30° の方向では、2 つのアンテナからの道のりが「間隔 × sin 30° = 半波長」だけ違います。半波長ずれた波は、山と谷が重なって打ち消し合います。方向によって道のりの差が変わるので、強め合う方向と打ち消し合う方向が生まれます。
- ミッション：2 つの素子からの電波が、ちょうど打ち消し合う方向（強さ 0）を探そう。
- 達成できる設定の例（検証で使用）：`{"look": 30}`

**ステップ 2　アレイファクタ**

- 問い：素子の間隔はそのままで、素子の数を 2 倍にする。正面のビームの幅はどうなる？
- 選択肢：A) 半分になる　**← 正解**　B) 変わらない　C) 2 倍になる
- 理由：ビームの幅は、アレイ全体の長さ（開口）が波長の何倍かで決まります。素子の数を 2 倍にすると開口が 2 倍になり、ビームの幅は半分になります。開口が大きいほど、正面から少しずれただけで、端の素子どうしの位相が大きくずれて打ち消し合うからです。
- ミッション：ビーム幅が 5° 以下になる、いちばん少ない素子の数を探そう。
- 達成できる設定の例（検証で使用）：`{"n": 21}`

**ステップ 3　位相をずらすとビームが向く**

- 問い：アンテナを動かさずに、ビームを右斜めへ向けたい。素子ごとの位相をどうすればよい？
- 選択肢：A) 全部の素子を、同じだけ遅らせる　B) 端から順に、一定の量ずつ位相をずらしていく　**← 正解**　C) 真ん中の素子だけ、位相を変える
- 理由：斜めの方向では、素子ごとに道のりが一定の量ずつ違います。その差をちょうど打ち消すように、端から順に位相をずらしておけば、その方向で全部の矢印がそろいます。全部を同じだけ遅らせても、そろう方向は正面のままです。
- ミッション：隣どうしの位相の差が、ちょうど 90° になる方向へビームを向けよう。
- 達成できる設定の例（検証で使用）：`{"th0": 30}`

**ステップ 4　グレーティングローブ**

- 問い：素子の数を節約しようと、素子の間隔を 1 波長まで広げた。パターンに何が起きる？
- 選択肢：A) ビームが消えてしまう　B) メインビームと同じ強さのビームが、別の方向にも現れる　**← 正解**　C) サイドローブが全部なくなる
- 理由：間隔が広いと、道のりの差がちょうど 1 波長（位相 360°）になる方向が、見える範囲に入ってきます。360° のずれは「ずれていない」のと同じなので、その方向でも全素子がそろい、メインビームと同じ強さのビームができます。
- ミッション：ビームを 30° に向けても、グレーティングローブのピークが見える範囲に入らない、いちばん広い素子の間隔を探そう。
- 達成できる設定の例（検証で使用）：`{"s": 0.65}`

**ステップ 5　走査による広がりと利得の低下**

- 問い：ビームを正面から 60° まで振る。ビームの幅と利得は、正面のときと比べてどうなる？
- 選択肢：A) 幅は約 2 倍に広がり、利得は約半分になる　**← 正解**　B) どちらも変わらない　C) 幅は半分になり、利得は 2 倍になる
- 理由：斜めの方向から見ると、アレイの面は cos θ₀ 倍に縮んで見えます（60° なら半分）。実質的なアンテナの大きさが半分になるので、ビームは 2 倍に太り、利得は半分（−3 dB）になります。これが、1 つの面で振れる角度が 60° 程度までとされる理由です。
- ミッション：利得が、正面のときよりちょうど 3 dB 下がる（半分になる）走査の角度を探そう。
- 達成できる設定の例（検証で使用）：`{"th0": 60}`

**ステップ 6　低サイドローブ**

- 問い：サイドローブを下げるために、アレイの端の素子ほど振幅を小さくする。その代わりに、何が起きる？
- 選択肢：A) ビームが細くなり、利得が上がる　B) ビームが太くなり、利得が下がる　**← 正解**　C) ほかには何も変わらない
- 理由：端を弱くすると、開口の端がなめらかに消えるので、サイドローブが下がります。その代わり、端の素子があまり働かなくなり、実質的な開口が小さくなります。そのためビームは太くなり、利得は下がります。
- ミッション：ピークサイドローブが −40 dB 以下になる重み付けを選び、ビーム幅と利得がどれだけ変わったかを確かめよう。
- 達成できる設定の例（検証で使用）：`{"wt": "ham"}`

**ステップ 7　移相器のビット数**

- 問い：移相器が、位相を 45° 刻み（3 ビット）でしか設定できないとする。パターンにどんな影響が出る？
- 選択肢：A) 影響はない　B) 利得が少し下がり、余分なローブ（量子化ローブ）が現れる　**← 正解**　C) ビームがまったく作れなくなる
- 理由：本当に必要な位相と、設定できる位相との差が、誤差になります。誤差の分だけ全素子のそろい方が悪くなり、利得が少し下がります。失われた電力はサイドローブへ回ります。誤差が規則的に並ぶと、特定の方向に余分なローブが立ちます。
- ミッション：量子化による利得の低下が 0.1 dB 以下になる、いちばん少ないビット数を探そう。
- 達成できる設定の例（検証で使用）：`{"bits": 4}`

**ステップ 8　帯域の影響**

- 問い：移相器の設定はそのままで、送る電波の周波数を少し上げる。60° に向けていたビームは、どうなる？
- 選択肢：A) そのまま 60° を向いている　B) 正面寄りに、少し戻る　**← 正解**　C) さらに外側へ振れる
- 理由：移相器は、周波数によらず同じ位相を与えます。一方、ビームを斜めに向けるのに必要な位相は、周波数に比例します。周波数を上げると、設定した位相では足りなくなり、ビームは正面寄りに戻ります。振る角度が大きいほど、ずれも大きくなります。
- ミッション：ビームのずれが、走査したビーム幅の 1/4 を超えない範囲で、周波数をできるだけ大きくずらそう（プラス側・マイナス側のどちらでもよい）。
- 達成できる設定の例（検証で使用）：`{"df": 1.6}`

**ステップ 9　複数ビーム・デジタルビーム形成・ヌルの形成**

- 問い：強い妨害電波が、サイドローブの方向から入ってくる。素子ごとの受信信号をデジタルで扱えるアレイなら、どう対処できる？
- 選択肢：A) アンテナ全体の感度を下げて、妨害を弱める　B) 重みを計算し直して、妨害の方向だけ感度がほぼ 0 の谷（ヌル）を作る　**← 正解**　C) 対処する方法はない
- 理由：素子ごとの信号がデジタルで手に入れば、足し合わせるときの重み（振幅と位相）を計算で自由に決められます。妨害の方向から来る電波だけが打ち消し合うように重みを選べば、その方向にヌルができます。目標の方向の感度は、ほとんど変わりません。
- ミッション：妨害の方向の感度が −50 dB 以下で、しかも正面（目標の方向）の利得の低下が 0.5 dB 以内に収まる、妨害の方向を 1 つ見つけよう。
- 達成できる設定の例（検証で使用）：`{"thj": 25}`

**ステップ 10　自由実験とまとめ**

- 問い：素子の間隔はそのままで、素子の数を 2 倍にする。ビーム幅と利得はどうなる？
- 選択肢：A) ビーム幅は半分になり、利得は 2 倍（+3 dB）になる　**← 正解**　B) ビーム幅は 2 倍になり、利得は半分になる　C) どちらも変わらない
- 理由：素子の数を 2 倍にすると、開口が 2 倍になります。ビーム幅は開口に反比例するので半分に、利得は素子の数に比例するので 2 倍になります。ただし、素子と移相器の数も 2 倍になり、費用が増えます。
- ミッション：ビームを 45° に向けて、グレーティングローブなし、ピークサイドローブ −30 dB 以下、ビーム幅 6° 以下のアレイを作ろう。
- 達成できる設定の例（検証で使用）：`{"th0": 45, "wt": "tay", "n": 36}`

**判定が「一致」でない項目の説明（不一致はなし）**

- **ヌルの形成の例：参考。** ハンドブックに数値例がないため、ステップ 9 の計算（16 素子、妨害対雑音比 50 dB）の結果だけを示しています。

**一致としたが、差のある項目**

- **表13.1（重み付けごとの効率・サイドローブ・ビーム幅の係数）。** 120 素子のアレイで数値計算した値です。サイドローブは 0.5 dB 以内、ビーム幅の係数は 1.2 以内で合います。表は連続した開口の理論値、こちらは有限個の素子での計算という違いによる差とみています。
- **式13.25（量子化による利得の低下、2／3／4 ビットで 1.0／0.23／0.06 dB）。** 計算値は 0.90／0.22／0.05 dB です。式は位相誤差が一様に分布するとした近似で、2 ビットでは近似の誤差が出ます。
- **図13.23（量子化ローブ、3〜6 ビットで −18〜−36 dB）。** 計算値は −17.1／−23.6／−29.4／−35.6 dB で、図の読み取りと 1 dB 以内です。
- **走査したビーム幅（正面の値 ÷ cosθ₀）。** 60° では式 6.35° に対して 6.38° です。式が近似であるためです。

**モデル化で補った点**

- 等間隔の直線アレイ（1 次元）だけを扱いました。平面アレイ、三角配列、相互結合、素子の故障は扱っていません。
- 素子パターンは cosθ（電力）としました。
- 帯域のステップは、移相器だけで走査する場合（時間遅延なし）の計算です。サブアレイごとの時間遅延は、読み物で触れるにとどめています。

### 3.5 新人がつまずきやすい誤解（各ステップの「④よくある誤解」）

| # | ステップ | よくある誤解と、その直し方 |
|---|---|---|
| 1 | アレイとは | 「アンテナを 2 つにすれば、どの方向にも 2 倍の電波が出る」わけではありません。合計の電力は同じで、方向による配分が変わるだけです。強くなる方向があれば、弱くなる方向もあります。 |
| 2 | アレイファクタ | 「素子を増やすと、サイドローブも下がる」と思いがちですが、いちばん大きいサイドローブの高さ（−13.3 dB）は、素子の数によらずほぼ同じです。変わるのは、ビームとサイドローブの幅です。 |
| 3 | 位相でビームを振る | 「ビームを 30° 向けるには、位相を 30° ずらす」ではありません。必要な位相の差は、素子の間隔と sin θ₀ で決まります。また、位相は 360° で元に戻るので、移相器は 0〜360° の範囲を設定できれば足ります。 |
| 4 | グレーティングローブ | 「グレーティングローブは、大きめのサイドローブのこと」ではありません。サイドローブは重み付けで下げられますが、グレーティングローブはメインビームと同じ強さで、重み付けでは下がりません。素子の間隔で防ぐものです。 |
| 5 | 走査と利得 | 「電子的に振るのだから、どの方向でも同じ性能」ではありません。振るほど利得は下がり、ビームは太ります。探知距離も角度の精度も、正面がいちばん良く、端へ行くほど悪くなります。 |
| 6 | 低サイドローブ | 「重み付けを工夫すれば、サイドローブはいくらでも下げられる」わけではありません。設計上は −40 dB でも、素子ごとの誤差が大きければ、誤差によるサイドローブがそれより高く残ります。 |
| 7 | 移相器のビット数 | 「ビット数は多いほど良いので、できるだけ増やす」とは限りません。ビット数を増やすと、移相器の損失、制御の複雑さ、費用が増えます。必要なサイドローブと指向精度から決めます。 |
| 8 | 帯域の影響 | 「ずれの角度は開口によらないのだから、大きなアレイでも帯域は同じ」ではありません。大きなアレイほどビームが細いので、同じずれでも、ビーム幅に対する割合が大きくなり、利得が大きく下がります。 |
| 9 | 複数ビームとヌル | 「ヌルを作れば、どの方向の妨害も消せる」わけではありません。妨害がメインビームの中に入ると、ヌルを作るためにメインビーム自体が崩れ、目標への感度も大きく下がります。 |
| 10 | 自由実験 | この図は、誤差のない理想的なアレイのパターンです。実際には、素子どうしの影響（相互結合）、振幅や位相の誤差、故障した素子などで、サイドローブは設計値より高くなります。 |

### 4.2 問い・選択肢・正解・ミッション

**ステップ 1　追尾レーダとは**

- 問い：追尾レーダのビームを細くしていく。良いことと、困ることの組み合わせで正しいのは？
- 選択肢：A) 角度が細かく分かり、他の物体のエコーも入りにくくなる。ただし、目標をビームに入れるのが難しくなる　**← 正解**　B) 角度は粗くなるが、目標を見つけやすくなる　C) 良いことだけで、困ることはない
- 理由：細いビームは、目標の方向を細かく決められ、となりの物体のエコーも締め出せます。そのかわり、見える範囲が狭いので、自分で空全体を探すのには向きません。ふつうは、捜索レーダなどから「このあたり」という指示をもらって、目標をビームに入れます。
- ミッション：指示の誤差が 1° ある目標を −3 dB 以内に入れ、3° 離れた別の物体は −20 dB 以下に抑えられるビーム幅を探そう。
- 達成できる設定の例（検証で使用）：`{"thb": 2.2}`

**ステップ 2　ビームを振って比べる方式**

- 問い：円錐走査では、ビームを軸のまわりに回し、エコーの強さの変化から角度のずれを知る。目標のエコーの強さ自体がパルスごとにゆらぐと、どうなる？
- 選択肢：A) ゆらぎを「角度のずれ」と見まちがえて、誤差が出る　**← 正解**　B) 1 回転のあいだに平均されるので、影響はない　C) ゆらぐほど、角度は正確になる
- 理由：円錐走査は、時間をずらして受けたパルスの強さを比べます。比べているあいだに目標のエコーの強さが変わると、それがビームの向きによる変化なのか、目標のゆらぎなのかを区別できません。目標が軸の真ん中にいても、ずれているように見えてしまいます。
- ミッション：目標を軸上（ずれ 0°）に置いたまま、ゆらぎを大きくして、推定のばらつき（RMS）が 0.5° を超えることを確かめよう。
- 達成できる設定の例（検証で使用）：`{"off": 0, "m": 0.4}`

**ステップ 3　モノパルス**

- 問い：2 つのビームで同時に受けた信号から「差 ÷ 和」を作る。目標のエコーが 1/10 に弱くなったら、この値はどうなる？
- 選択肢：A) 変わらない（割り算で、強さが打ち消される）　**← 正解**　B) 1/10 になる　C) 10 倍になる
- 理由：2 つのビームは同じパルスを同時に受けるので、エコーが弱くなれば、和も差も同じ割合で小さくなります。割り算をすると強さは打ち消されて、目標の方向だけで決まる値が残ります。これが、エコーのゆらぎに強い理由です。
- ミッション：Δ/Σ がちょうど +0.50（±0.02）になる目標の角度を探そう。
- 達成できる設定の例（検証で使用）：`{"tg": 1}`

**ステップ 4　誤差の傾き**

- 問い：2 つのビームの開きを大きくする。Δ/Σ の傾き（角度のずれに対する感度）と、軸上の和信号の強さはどうなる？
- 選択肢：A) 傾きは急になるが、和信号は弱くなる　**← 正解**　B) 傾きも和信号も大きくなる　C) 傾きは緩やかになり、和信号は強くなる
- 理由：ビームを大きく開くと、少しのずれで 2 つのビームの差が大きく変わるので、傾きは急になります。そのかわり、どちらのビームも軸からそっぽを向くので、軸上の目標から受ける和信号は弱くなります。感度と信号の強さは、取り合いの関係にあります。
- ミッション：誤差の傾き km が、ハンドブックの代表値 1.57 に近い値（1.50〜1.65）になるビームの開きを探そう。
- 達成できる設定の例（検証で使用）：`{"sq": 0.85}`

**ステップ 5　サーボと距離の追尾**

- 問い：アンテナを動かすサーボの帯域（反応の速さ）を広げていく。動いている目標に対する追尾の誤差はどうなる？
- 選択肢：A) 遅れは減るが、雑音でふらつきやすくなる。ちょうどよい帯域がある　**← 正解**　B) 広げるほど、誤差は小さくなり続ける　C) 狭めるほど、誤差は小さくなり続ける
- 理由：帯域を広げると、サーボは誤差信号にすばやく反応するので、動く目標への遅れは減ります。しかし、雑音による誤差信号のふらつきにもすばやく反応してしまいます。遅れと雑音の合計が最小になる帯域が、途中にあります。
- ミッション：遅れと雑音を合わせた誤差が 0.040° 以下になるサーボ帯域を探そう。
- 達成できる設定の例（検証で使用）：`{"bn": 12}`

**ステップ 6　グリント**

- 問い：目標の両端に反射点が 2 つあり、エコーがほぼ逆の位相で打ち消し合っている。このとき、レーダが「ここだ」と指す位置は？
- 選択肢：A) 2 つの反射点の外側（目標の外）に出ることがある　**← 正解**　B) 必ず 2 つの反射点のあいだにある　C) 必ず強いほうの反射点の真上にある
- 理由：2 つのエコーが打ち消し合うと、和信号 Σ はとても小さくなります。差信号 Δ は同じようには小さくならないので、Δ/Σ が大きな値になります。その結果、レーダは 2 つの反射点のどちらよりも外側を指します。エコーが弱くなる瞬間ほど、角度は大きく外れます。
- ミッション：レーダが指す位置が、目標の外に出る位相差を見つけよう。
- 達成できる設定の例（検証で使用）：`{"phi": 160}`

**ステップ 7　低高度のマルチパス**

- 問い：海面すれすれを飛ぶ目標を追尾する。エコーは、直接の経路と、海面で反射した経路の 2 つから届く。追尾はどうなる？
- 選択肢：A) 海面の下の「像」と目標が 2 点の目標のようになり、仰角が大きくふらつく　**← 正解**　B) 反射のぶんエコーが強くなるので、仰角はより正確になる　C) 方位角が大きくふらつき、仰角は影響を受けない
- 理由：海面で反射したエコーは、海面の下にある「像」から来たように見えます。目標と像は上下に並んだ 2 つの反射点と同じなので、グリントと同じことが仰角の方向に起こります。像がビームの中に入るほど目標が低いと、誤差は大きくなります。
- ミッション：仰角を下げていき、仰角の誤差が 0.3° を超えるところを見つけよう。
- 達成できる設定の例（検証で使用）：`{"el": 1.35}`

**ステップ 8　誤差のまとめと低減**

- 問い：遠くから近づいてくる目標を追尾している。角度の追尾誤差（角度で表した値）は、距離とともにどう変わる？
- 選択肢：A) 近づくと小さくなるが、ある距離より近いと、グリントのために逆に大きくなる　**← 正解**　B) 近づくほど、どこまでも小さくなる　C) 距離によらず一定
- 理由：遠距離では S/N が低く、受信機の熱雑音による誤差が大きくなります。近づくと S/N が上がって熱雑音の誤差は減りますが、グリントは目標の幅で決まるので、角度に直すと距離に反比例して増えます。その結果、誤差が最小になる距離が途中にあります。
- ミッション：合計の誤差がいちばん小さくなる距離を探そう（最小値の +2% 以内）。
- 達成できる設定の例（検証で使用）：`{"R": 35}`

**ステップ 9　自由実験とまとめ**

- 問い：距離 100 km の目標に対する角度の誤差を小さくしたい。いちばん効くのは？
- 選択肢：A) ビームを細くする、または S/N を上げる　**← 正解**　B) 幅の小さい目標だけを追尾する　C) どれを変えても、遠距離の誤差は変わらない
- 理由：遠距離では、熱雑音による誤差が主役です。この誤差はビーム幅に比例し、S/N の平方根に反比例します。目標の幅が効くのはグリントで、遠距離では小さいので、ほとんど変わりません。まず「いま何が主役か」を見きわめるのが大事です。
- ミッション：距離 50 km の目標に対して、合計の誤差を 0.1 mrad 以下にしよう。
- 達成できる設定の例（検証で使用）：`{"R": 50, "thb": 1}`

**一致としたが、条件のある項目**

- **誤差の傾き km（1.2〜1.9、代表値 1.57）。** 2 ビームのモデルでは、ビームの開きで km が 0.95〜2.16 と変わります。標準に使った開き（ビーム幅の 0.4 倍）で 1.44 となり、ハンドブックの範囲に入ります。実際の km は給電部の方式で決まるもので、このモデルの「開き」とは対応が異なります。
- **式9.10（熱雑音による角度誤差）。** 式の値 20.96 ミリ度に対し、1 パルスごとに雑音を加えて 1 次のサーボで追尾したシミュレーションで 20.99 ミリ度でした。Bτ = 1、サーボのループ利得を 4βn とした場合です。

- p.9.31 の「実機の σang は 0.15L から 2.0L」は、直後の説明（小型機で約 0.1L、大型機で 0.2L に近づく）から、0.2L の誤記とみられます。

**モデル化で補った点**

- 角度は 1 方向（1 次元）だけを扱いました。ビームはガウス形で、サイドローブがありません。このため、マルチパスのステップでは、仰角が高いときの誤差が 0 になります（実際にはサイドローブから入る像による誤差が残ります。式9.8）。
- 円錐走査は、1 回転 16 パルス、パルス間で相関のあるゆらぎという簡単なモデルです。
- 誤差の見積もり（ステップ 8・9）は、熱雑音・グリント・その他の 3 つだけです。「その他 0.05 mrad」は説明用の値です。

### 5.2 問い・選択肢・正解・ミッション

**ステップ 1　伝搬因子とは**

- 問い：目標のいる場所で、電界の強さが自由空間のときの半分（伝搬因子 F = 0.5）だった。レーダに戻るエコーの電力は、自由空間のときの何分の 1 になる？
- 選択肢：A) 1/16　**← 正解**　B) 1/4　C) 1/2
- 理由：電界が半分なら、電力は 2 乗で 1/4 です。レーダの電波は、行きと帰りで同じ道を通るので、帰りにもう一度 1/4 になります。合わせて 1/16（−12 dB）です。探知距離は、電力の 4 乗根で効くので、ちょうど F 倍（半分）になります。
- ミッション：探知距離が、自由空間のときのちょうど半分（50 km、±1 km）になる伝搬因子を探そう。
- 達成できる設定の例（検証で使用）：`{"F": -6}`

**ステップ 2　大気と屈折**

- 問い：地表の近くでレーダの電波を水平に出す。ふつうの大気の中で、電波はどう進む？
- 選択肢：A) 少し下向きに曲がる（まっすぐ進む場合より、遠くの低い所まで届く）　**← 正解**　B) 上向きに曲がって、地表から離れていく　C) まったく曲がらず、まっすぐ進む
- 理由：空気は、上に行くほど薄くなり、屈折率が小さくなります。電波は屈折率の大きいほう（下）へ曲がるので、ふつうの大気では少し下向きに曲がります。ただし、曲がり方は地球の丸みよりゆるいので、電波はだんだん地表から離れていきます。
- ミッション：標準大気の勾配に合わせて、等価地球半径係数 k が 4/3（1.33）になることを確かめよう。
- 達成できる設定の例（検証で使用）：`{"dn": -39}`

**ステップ 3　電波の見通し距離**

- 問い：レーダのアンテナを 4 倍の高さに上げる。海面すれすれの目標が見える距離（水平線までの距離）は、何倍になる？
- 選択肢：A) 2 倍　**← 正解**　B) 4 倍　C) 変わらない
- 理由：水平線までの距離は、高さの平方根に比例します。高さを 4 倍にしても、距離は 2 倍にしかなりません。逆にいえば、遠くの低い目標を見るには、アンテナを思い切って高くする必要があります。航空機にレーダを載せる理由の 1 つです。
- ミッション：高さ 10 m を飛ぶ目標を、40 km 以上の距離で見通せる、いちばん低いアンテナの高さを探そう（目標の高さは 10 m のまま）。
- 達成できる設定の例（検証で使用）：`{"h1": 43, "h2": 10}`

**ステップ 4　海面反射による干渉**

- 問い：海の上の目標が、同じ距離のまま、高さだけを少しずつ上げていく。目標に届く電波の強さはどうなる？
- 選択肢：A) 強くなったり弱くなったりを、何度も繰り返す　**← 正解**　B) 高いほど、一様に強くなる　C) 高さによらず一定
- 理由：目標には、まっすぐ届く直接波と、海面で反射して届く反射波の 2 つが届きます。高さが変わると 2 つの道のりの差が変わり、山と山が重なって強め合う高さと、山と谷が重なって打ち消し合う高さが、交互に現れます。
- ミッション：伝搬因子が −10 dB 以下になる（打ち消し合う）高さを見つけよう。
- 達成できる設定の例（検証で使用）：`{"ht": 120}`

**ステップ 5　カバレッジ図**

- 問い：アンテナの高さはそのままで、レーダの周波数を高くする（波長を短くする）。海面反射でできるローブは、どう変わる？
- 選択肢：A) ローブが細かくなって数が増え、いちばん下のローブは海面に近づく　**← 正解**　B) ローブが太くなって数が減り、いちばん下のローブは高くなる　C) ローブの形は、周波数では変わらない
- 理由：ローブは、直接波と反射波の道のりの差が、波長の半分だけ変わるごとに 1 つできます。波長が短いと、少し角度が変わるだけで山と谷が入れかわるので、ローブは細かくなります。いちばん下のローブの仰角は λ/(4·h₁) で、波長が短いほど海面に近づきます。
- ミッション：いちばん下のローブの仰角が 0.1° 以下になる周波数を選ぼう。
- 達成できる設定の例（検証で使用）：`{"f": 3}`

**ステップ 6　異常伝搬（ダクト）**

- 問い：海の上に、暖かく乾いた空気が流れ込み、海面の近くに特別な空気の層ができた。レーダの電波はどうなることがある？
- 選択肢：A) 層の中に閉じ込められ、水平線のずっと先まで届く　**← 正解**　B) 層にすべて吸収されて、近くしか見えなくなる　C) 層ができても、電波の進み方は変わらない
- 理由：高さとともに屈折率が急に減る層の中では、電波は地球の丸みより強く下向きに曲がります。下に曲がった電波は海面で反射し、また上に向かい、また曲げ戻されます。こうして層の中に閉じ込められ、広がらずに遠くまで届きます。
- ミッション：波長 10 cm（3 GHz）の電波まで閉じ込められる、いちばん薄いダクトの高さを探そう。
- 達成できる設定の例（検証で使用）：`{"td": 20}`

**ステップ 7　自由実験とまとめ**

- 問い：風が強くなって海が荒れ、海面の反射係数が小さくなった。ローブとヌルのしま模様はどうなる？
- 選択肢：A) 山も谷も浅くなり、自由空間（F = 1）に近づく　**← 正解**　B) 山はもっと高く、谷はもっと深くなる　C) しま模様の位置が、上にずれる
- 理由：反射波が弱くなると、直接波に足しても引いても、あまり変わらなくなります。強め合う所の利益（最大 +6 dB）は減りますが、打ち消し合う所の谷も浅くなります。反射係数が 0 なら、どこでも F = 1 で、自由空間と同じになります。
- ミッション：距離 40 km・高度 100 m の目標の位置で、伝搬因子を +3 dB 以上にしよう。
- 達成できる設定の例（検証で使用）：`{"f": 3}`

| 位相（phase） | 波の「1 周期のうちのどこにいるか」を角度で表したもの。360° で 1 周する。 |
| ドップラ周波数（Doppler frequency） | 目標が近づく・遠ざかることで、エコーの周波数が送信からずれる量。fd = 2v/λ（v は近づく速度、λ は波長）。 |
| PRF（pulse repetition frequency、パルス繰り返し周波数） | 1 秒間に送るパルスの数。逆数がパルスの間隔。 |
| 距離セル／レンジゲート（range cell / range gate） | 受信信号を、距離（遅れ時間）ごとに細かく区切った 1 区画。 |
| クラッタ（clutter） | 地面・海面・雨など、見たい目標以外からの不要なエコー。 |
| サイドローブ（sidelobe） | 本来のピーク（主ローブ）の両脇に出る小さな山。強い信号のサイドローブが、弱い信号を隠すことがある。 |
| 重み付け（weighting） | データの端を小さくするような係数を掛けて、サイドローブを下げる処理。代わりに主ローブが少し広がり、S/N が少し下がる。 |
| FFT（高速フーリエ変換） | 信号を周波数の成分に分ける計算を、高速に行う方法。 |

### 第0回 レーダの基礎の基礎

| 用語（日本語／英語） | 説明 |
|---|---|
| レーダ（radar） | 電波を出し、物に当たってはね返ってきた電波（エコー）を受けて、物の存在と位置を知る装置。 |
| 目標（target） | レーダが見つけたい物。航空機、船、車、雨雲など。電波をはね返す物なら何でも目標になりうる。 |
| エコー（echo） | 目標に当たってはね返り、レーダに戻ってきた電波。送信した電力に比べてけた違いに弱い。 |
| 波長（wavelength） | 波の山から次の山までの長さ。光の速さ ÷ 周波数。3 GHz で 10 cm、10 GHz で 3 cm。 |
| パルス幅（pulse width） | 1 回に電波を出している時間の長さ。1 µs なら、空間では 300 m の長さの電波のかたまりになる。 |
| 尖頭電力と平均電力（peak power / average power） | 尖頭電力はパルスを出している間の電力。平均電力は、出していない時間も含めてならした電力で、尖頭電力 × パルス幅 × PRF。 |
| レーダ方程式（radar equation） | レーダの性能（電力、アンテナ、雑音など）と、目標の大きさ・距離から、受信電力や最大探知距離を見積もる式。受信電力は距離の 4 乗に反比例する。 |
| レーダ断面積（RCS、radar cross section） | 目標がレーダから「どれくらい大きく見えるか」を面積 [m²] で表した量。実際の大きさとは一致しない。第10回で詳しく扱う。 |
| アンテナ利得（antenna gain） | アンテナが電波を特定の方向にどれだけ集中させるかを表す倍率。全方向に均等に出す場合と比べた値。 |
| 有効開口面積（effective area） | 受信アンテナが電波を集める「実質的な広さ」[m²]。利得 G とは G = 4π·Ae/λ² の関係がある。 |
| 最小検出信号（minimum detectable signal） | 検出できる、いちばん弱いエコーの電力。受信機の雑音で決まる。 |
| 雑音指数（noise figure） | 実際の受信機の雑音が、理想的な受信機の何倍かを表す値。小さいほど良い。 |
| ビーム幅（beamwidth） | アンテナが電波を集中させる角度の幅。ふつうは、強さが半分（−3 dB）になる 2 方向の間の角度。アンテナが波長に比べて大きいほど狭い。 |
| 周波数帯（letter band） | レーダの周波数の範囲を表す文字の名前。L 帯（1〜2 GHz）、S 帯（2〜4 GHz）、X 帯（8〜12 GHz）など。 |
| 監視レーダ（surveillance radar） | 広い範囲を繰り返し見張り、目標を見つけるレーダ。捜索レーダともいう。 |
| 追尾レーダ（tracking radar） | 目標の動き（航跡）を求めるレーダ。1 つの目標にビームを向け続ける方式と、見張りながら多数の目標を追う方式がある。 |
| 再訪時間（revisit time） | 監視レーダが同じ方向をもう一度見るまでの時間。アンテナが 1 回転する時間にあたる。 |

### 第1回 パルス圧縮

| 用語（日本語／英語） | 説明 |
|---|---|
| パルス圧縮（pulse compression） | 変調をかけた長いパルスを送り、受信側のフィルタで細いパルスに戻す方法。長いパルスのエネルギーと、短いパルスの距離分解能を両立させる。 |
| 時間帯域幅積（time-bandwidth product） | パルス幅 T と帯域 B の積 TB。パルス圧縮比にほぼ等しい。 |
| パルス圧縮比（pulse compression ratio） | 送信パルス幅と、圧縮後のパルス幅の比。およそ TB。 |
| 距離分解能（range resolution） | 近くにある 2 つの目標を別々に見分けられる最小の距離差。およそ c/(2B)。 |
| LFM／チャープ（linear frequency modulation） | パルスの中で周波数を直線的に変える変調。代表的なパルス圧縮波形。 |
| 整合フィルタ（matched filter） | 送信波形に合わせて作った受信フィルタ。雑音の中の信号に対して、出力のピークの S/N を最大にする。 |
| 時間サイドローブ（time sidelobe） | 圧縮後のパルスで、主ローブの前後（距離方向）に出る小さな山。 |
| テイラー重み付け（Taylor weighting） | LFM の時間サイドローブを下げるための、代表的な周波数領域の重み付け。 |
| ミスマッチ損失（mismatch loss） | 重み付けなどで整合フィルタからわざと外したために生じる S/N の低下。 |
| 距離ドップラ結合（range-Doppler coupling） | LFM で、目標のドップラ周波数によって圧縮後のピークの位置（距離）がずれる現象。 |
| 位相符号波形（phase-coded waveform） | パルスを短いサブパルスに分け、サブパルスごとに位相を切り替える波形。 |
| バーカー符号（Barker code） | サイドローブが主ローブの 1/N になる特別な 2 値位相符号。長さは最大 13。 |
| エクリプシング（eclipsing） | 送信中は受信機がオフなので、その間に戻ってきたエコーが欠けること。 |
| ストレッチ処理（stretch processing） | 受信した LFM に参照の LFM を掛け、周波数の違いとして距離を読み取る圧縮方法。 |

### 第2回 MTI（移動目標指示）

| 用語（日本語／英語） | 説明 |
|---|---|
| MTI（moving target indication、移動目標指示） | パルスごとのエコーの変化を使って、止まっているクラッタを消し、動いている目標を残す処理。 |
| パルスキャンセラ（delay-line canceler） | 1 つ前のパルスのエコーを引き算する MTI フィルタ。固定物のエコーは毎回同じなので消える。 |
| ブラインド速度（blind speed） | MTI で目標まで消えてしまう速度。ドップラ周波数が PRF の整数倍になる速度。 |
| 改善度（improvement factor） | MTI によって、信号対クラッタ比がどれだけ良くなったかを表す値（全速度で平均）。 |
| クラッタ減衰（clutter attenuation） | MTI フィルタの入力と出力での、クラッタ電力の比。 |
| スタガPRF（staggered PRF） | パルスの間隔を交互に変えることで、ブラインド速度を高い速度へ追いやる方法。 |
| クラッタのスペクトル拡がり（clutter spectral spread） | 風で揺れる木やアンテナの走査などで、クラッタのドップラが 0 のまわりに幅を持つこと。 |
| 走査変調（scanning modulation） | アンテナが回ることで、クラッタのエコーの強さがパルスごとに変わること。スペクトル拡がりの原因の 1 つ。 |
| クラッタマップ（clutter map） | 場所ごとに、過去のスキャンのクラッタの強さを記憶したもの。しきい値の設定などに使う。 |

### 第3回 パルスドップラ

| 用語（日本語／英語） | 説明 |
|---|---|
| パルスドップラ（pulse Doppler） | パルス列のエコーを距離ごとにドップラ分析し、速度ごとに分けて目標を検出する方式。 |
| ドップラフィルタ（Doppler filter） | 特定のドップラ周波数（速度）の成分だけを通すフィルタ。FFT で多数並べて作る。 |
| コヒーレント処理区間（CPI、coherent processing interval） | まとめてドップラ分析する 1 かたまりのパルス列。長いほどドップラ分解能が細かい。 |
| 距離のあいまいさ（range ambiguity） | エコーがどの送信パルスのものか区別できず、距離が決まらないこと。PRF が高いほど起きやすい。 |
| ドップラのあいまいさ（Doppler ambiguity） | ドップラ周波数が PRF の整数倍だけ違うものと区別できないこと。PRF が低いほど起きやすい。 |
| メインビームクラッタ（mainbeam clutter） | アンテナの主ビームが地面に当たって返ってくる強いクラッタ。 |
| サイドローブクラッタ（sidelobe clutter） | アンテナのサイドローブを通って、あらゆる方向の地面から返ってくるクラッタ。 |
| 高度線（altitude line） | 航空機の真下の地面からのクラッタ。ドップラがほぼ 0 の位置に強く出る。 |
| ブラインドゾーン（blind zone） | エクリプシングやクラッタのために目標が見えなくなる、距離やドップラの範囲。 |

### 第4回 自動検出とCFAR

| 用語（日本語／英語） | 説明 |
|---|---|
| しきい値（threshold） | 「これを超えたら目標あり」と判定する基準の値。 |
| 探知確率（probability of detection、Pd） | 目標があるときに、正しく検出できる確率。 |
| 誤警報確率（probability of false alarm、Pfa） | 目標がないのに、雑音などで「目標あり」と判定してしまう確率。 |
| 積分（integration） | 何パルス分かの受信信号を足し合わせて、目標を検出しやすくすること。 |
| 移動窓積分器（moving-window integrator） | 直近の n パルスの和を、1 パルスごとに更新していく積分器。 |
| 2値積分（binary integration） | パルスごとに 0／1 を判定し、N 回のうち M 回以上 1 なら検出とする方法（M-out-of-N）。 |
| CFAR（constant false alarm rate、一定誤警報率） | 背景の強さに合わせてしきい値を自動で変え、誤警報確率を一定に保つ処理。 |
| セル平均CFAR（cell-averaging CFAR） | 注目するセルの周りのセル（参照セル）の平均から背景の強さを推定する CFAR。 |
| 参照セル（reference cells） | CFAR で、背景の強さを推定するために使う周りのセル。 |
| CFAR損失（CFAR loss） | 背景を推定で求めるために、しきい値を高めにする必要があり、その分だけ余分に必要になる S/N。 |
| Swerlingモデル（Swerling models） | 目標のエコーの強さのゆらぎ方を表す代表的なモデル（スキャンごとに変わるか、パルスごとに変わるか、など）。 |

### 第5回 自動追尾

| 用語（日本語／英語） | 説明 |
|---|---|
| 航跡（track） | 「ここに目標がいて、こう動いている」という、レーダの推定結果。何回分もの検出点をつないで作る。位置と速度を持つ。 |
| 検出点／プロット（detection / plot） | 1 回のスキャンで、しきい値を超えた信号を 1 つの点（距離と方向）にまとめたもの。目標のほか、誤警報やクラッタも混ざる。 |
| 航跡ファイル（track file） | 追尾中のすべての航跡について、番号、位置、速度、最後に更新した時刻などを記録した一覧。 |
| 対応付け（association） | 新しい検出点が、どの航跡のものかを決めること。相関ともいう。 |
| ゲート（gate） | 航跡の予測位置のまわりに設ける範囲。この中に入った検出点だけを、その航跡の候補にする。 |
| 統計距離（statistical distance） | 検出点と予測位置のずれを、測定の精度で割って数えた距離。精度の良い方向のずれは大きく、粗い方向のずれは小さく数える。 |
| 最近傍法（nearest neighbor） | 統計距離がいちばん小さい検出点と航跡の組から、順に割り当てていく方法。もっともよく使われる。 |
| GNN（global nearest neighbor） | 検出点と航跡の組み合わせ全体を見て、統計距離の合計などが最小になる割り当てを選ぶ方法。 |
| 平滑化と予測（filtering / prediction） | 平滑化は、測定のばらつきをならして現在の位置・速度を推定すること。予測は、次の測定の時刻にいる位置を計算すること。 |
| α-βフィルタ（α-β filter） | 予測と測定の差に、決まった重み（α：位置、β：速度）を掛けて修正する、いちばん簡単な追尾フィルタ。 |
| 追尾ゲイン（tracking gain） | 予測と測定の差を、どれだけ推定に反映するかを決める重み。大きいと測定を重く、小さいと予測を重く見る。 |
| 遅れ（lag） | 目標が旋回や加速をしたとき、航跡が実際の位置に追いつかずに生じる、かたよった誤差。 |
| 機動（maneuver） | 目標が、フィルタの前提（等速直線など）から外れた動きをすること。旋回、加速、減速など。 |
| カルマンフィルタ（Kalman filter） | 測定の精度、測定の間隔、想定する機動の大きさから、追尾ゲインを毎回計算するフィルタ。α-βフィルタの重みを自動で変えるものと考えられる。 |
| 追尾指数（track filtering parameter） | 想定する機動の大きさ、測定の間隔、測定の精度を 1 つにまとめた、単位のない数。大きいほど追尾ゲインが大きくなる。 |
| 航跡の開始（track initiation） | どの航跡にも対応しない検出点から、新しい航跡を作ること。5 回の機会のうち 4 回の検出、のような基準を使う。 |
| 偽航跡（false track） | 目標ではないものにできてしまった航跡。無関係な誤警報やクラッタがたまたま並んでできるものと、鳥のように興味のない物にできるものがある。 |
| アクティビティ制御（activity control） | 検出点が多すぎる領域で、検出の条件を厳しくして、追尾処理に入れる検出点の数を抑えること。 |
| 多重仮説追尾（MHT、multiple hypothesis tracking） | 対応付けを 1 つに決めず、複数の可能性（仮説）を並行して追い、後の測定でありそうにないものを捨てていく方法。 |
| PDA／JPDA（probabilistic data association） | ゲート内の検出点を 1 つに絞らず、「その航跡のものである確率」で重み付けして、まとめて更新に使う方法。 |

### 第6回 航空機搭載MTI（AMTI）

| 用語（日本語／英語） | 説明 |
|---|---|
| AMTI（airborne MTI、航空機搭載MTI） | 航空機に載せたレーダで使う MTI。レーダ自身が動くので、地面のクラッタにもドップラが付く点が、地上のレーダと違う。 |
| プラットフォーム（platform） | レーダを載せている乗り物。ここでは航空機のこと。 |
| 対地速度（ground speed） | 地面に対する機体の速さ。クラッタのドップラは、この速度で決まる。 |
| ボアサイト（boresight） | アンテナのビームの中心の方向。 |
| 俯角（depression angle） | 水平から下向きに測った、見下ろす角度。 |
| スラントレンジ（slant range） | レーダから地面の点までの、斜めの直線距離。 |
| プラットフォーム運動スペクトル（platform-motion spectrum） | 機体が動くために、ビームの中の方向ごとにクラッタのドップラが少しずつ違い、その結果として広がったクラッタのスペクトル。真横を見たときにいちばん広い。 |
| TACCAR（time-averaged clutter coherent airborne radar） | クラッタのエコーの平均的なドップラを測り、それが 0 になるように周波数をずらして、メインビームクラッタを MTI のノッチに合わせる方法。 |
| 位相中心（phase center） | アンテナが電波を出し入れしている「見かけの 1 点」。開口の中での重みの付け方で、位置を動かせる。 |
| DPCA（displaced phase center antenna） | パルスごとにアンテナの位相中心をずらして、機体が進んだ分を打ち消し、クラッタからはアンテナが止まっているように見せる方法。 |
| 和パターンと差パターン（sum / difference pattern） | アンテナの左右半分の信号を、足して作るビーム（和）と、引いて作るビーム（差）。差パターンは、中心で 0、左右で符号が反対になる。 |
| ステップ走査補償（step-scan compensation） | アンテナが回ることによるエコーの振幅の変化を、差パターンを使って打ち消す方法。ビームを電子的に少し前後に向け、止まっていたように見せる。 |
| CPCT（coincident phase center technique） | 位相中心を開口の前後にもずらして、進行方向の動きによるクラッタの拡がりも打ち消す方法。 |
| STAP（space-time adaptive processing、時空間適応処理） | アンテナの素子ごと（空間）、パルスごと（時間）の信号に、受信したデータから計算した重みを掛けて足し合わせ、クラッタや妨害を消す処理。 |
| 自由度（degrees of freedom） | 適応処理で自由に決められる重みの数。素子の数 × パルスの数が上限。多いほど細かく消せるが、計算と必要なデータが増える。 |

### 第7回 フェーズドアレイアンテナ

| 用語（日本語／英語） | 説明 |
|---|---|
| フェーズドアレイ（phased array） | 小さなアンテナ（素子）をたくさん並べ、素子ごとの位相を変えることで、アンテナを動かさずにビームの向きを変えるアンテナ。 |
| 素子（radiating element） | アレイを作る 1 つ 1 つの小さなアンテナ。 |
| 開口（aperture） | アンテナが電波を出し入れする面。直線アレイでは、素子の数 × 素子の間隔が開口の長さ。 |
| アレイファクタ（array factor） | 素子がどの方向にも同じ強さで出すと仮定したときの、並べ方と位相だけで決まるパターン。 |
| 素子パターン（element pattern） | 素子 1 個が持つ、方向ごとの強さ。アレイ全体のパターンは、素子パターン × アレイファクタ。 |
| 移相器（phase shifter） | 素子ごとの信号の位相をずらす部品。ふつうはデジタル制御で、ビット数に応じた刻みでしか設定できない。 |
| ビーム走査（beam scanning） | ビームの向きを変えること。フェーズドアレイでは、素子から素子へ一定の量ずつ位相をずらして行う。 |
| グレーティングローブ（grating lobe） | 素子の間隔が広すぎるときに、メインビームと同じ強さで別の方向に現れるビーム。 |
| 照射分布（illumination function） | 開口の上での振幅の付け方。端を弱くするとサイドローブが下がり、ビームが太くなる。 |
| 開口効率（aperture efficiency） | 重み付けなどで、一様な照射のときより利得がどれだけ下がるかを表す比。 |
| 位相の量子化（phase quantization） | 移相器が決まった刻みでしか位相を設定できないために生じる誤差。 |
| 量子化ローブ（quantization lobe） | 位相や振幅の量子化誤差が規則的に並ぶことで、特定の方向に現れる余分なローブ。 |
| 開口充填時間（aperture fill time） | 斜めから来たパルスが、アレイの端から端まで行き渡るのにかかる時間。アレイの帯域を決める。 |
| 時間遅延走査（time-delay scanning） | 位相ではなく時間の遅れでビームを向ける方法。周波数が変わってもビームの向きが変わらない。 |
| サブアレイ（subarray） | アレイをいくつかの素子のまとまりに分けたもの。まとまりごとに受信機や時間遅延を持たせる。 |
| デジタルビーム形成（DBF、digital beamforming） | 素子またはサブアレイごとに信号をデジタルにしてから、計算で重みを掛けて足し、ビームを作る方法。複数のビームを同時に作れる。 |
| ヌル（null） | パターンの中で、感度がほぼ 0 になる方向。妨害の方向にヌルを向けると、妨害を抑えられる。 |

### 第8回 モノパルス測角と追尾レーダ

| 用語（日本語／英語） | 説明 |
|---|---|
| モノパルス（monopulse） | 複数のビームで同時に受けた信号を比べて、1 つのパルスだけで目標の角度のずれを求める方式。同時ローブ（simultaneous lobing）ともいう。 |
| 振幅比較モノパルス（amplitude-comparison monopulse） | 向きを少しずつずらした複数のビームで受けた信号の、振幅の違いから角度のずれを求めるモノパルス。 |
| 和信号と差信号（sum / difference signals、Σ・Δ） | 複数のビームの信号を足したもの（和、Σ）と引いたもの（差、Δ）。和は目標の検出と距離の測定に、差は角度のずれの測定に使う。 |
| コンパレータ（comparator） | ホーン（給電部）の信号を足し引きして、和信号と差信号を作るマイクロ波の回路。 |
| 角度誤差信号（angle-error signal） | アンテナの軸と目標の方向のずれを表す信号。モノパルスでは、差信号を和信号で割って作る。大きさがずれの量、符号がずれの向きを表す。 |
| 誤差の傾き（error slope、km） | 目標が軸から少しずれたときに、角度誤差信号（Δ/Σ）がどれだけ変わるかを表す値。ビーム幅 1 つぶんのずれに対する変化で表す。大きいほど、雑音に強い。 |
| ビームの開き（beam offset、squint angle） | 角度を測るために、ビームをアンテナの軸からわざとずらす角度。 |
| 円錐走査（conical scan） | 軸から少しずらしたビームを、軸のまわりに回す方式。エコーの強さの変化（変調）の大きさと位相から、角度のずれを求める。 |
| ローブ切替（sequential lobing） | ビームの向きを、いくつかの位置に順番に切り替えて、エコーの強さを比べる方式。 |
| AGC（automatic gain control、自動利得制御） | 信号の強さが変わっても出力が一定になるように、受信機の利得を自動で変えるしくみ。モノパルスでは、和信号で割り算をする役目を持つ。 |
| サーボ（servo） | 誤差信号が 0 になるように、アンテナを自動で動かすしくみ。 |
| サーボ帯域（servo bandwidth） | サーボがどのくらい速い変化まで追いかけられるかを表す周波数。広いほど反応が速いが、雑音の影響も受けやすい。 |
| 捕捉（acquisition） | 追尾を始めるために、目標をビームと距離ゲートの中にとらえること。 |
| 早期ゲートと後期ゲート（early / late gates） | 距離ゲートを前半と後半に分けたもの。それぞれに入るエコーの量を比べて、ゲートの中心と目標の距離のずれを求める。 |
| グリント（glint、角度雑音） | 目標の中の複数の反射点からのエコーが干渉して、レーダが指す方向がふらつくこと。目標の外を指すこともある。 |
| シンチレーション（scintillation、振幅雑音） | 目標のエコーの強さが、時間とともにゆらぐこと。 |
| マルチパス（multipath） | 電波が、直接の経路と、地面や海面で反射した経路の、2 つ以上の経路で届くこと。 |
| 像（image） | 地面や海面の反射で、表面の下に目標があるように見えるもの。鏡に映った姿にあたる。 |
| ミリラジアン（mrad） | 角度の単位。1 mrad = 0.001 ラジアン ≈ 0.057°。距離 1 km で幅 1 m に見える角度。 |

### 第9回 電波の伝わり方（伝搬）

| 用語（日本語／英語） | 説明 |
|---|---|
| 伝搬（propagation） | 電波が空間を伝わること。大気や地面・海面の影響で、伝わり方が変わる。 |
| 自由空間（free space） | 地球や大気の影響がまったくない、理想的な空間。伝わり方を比べるときの基準にする。 |
| 伝搬因子（propagation factor、F） | 実際の電界の強さを、同じ距離の自由空間での電界の強さで割った値。1 より大きければ自由空間より強く、小さければ弱い。 |
| 自由空間伝搬損失（free-space path loss） | 自由空間で、電波が球面状に広がるために、距離とともに弱まる量。 |
| 伝搬損失（propagation loss） | 送信してから受信するまでに電波が弱まる量。自由空間伝搬損失から、伝搬因子のぶんを引いたもの。 |
| 屈折（refraction） | 電波が、空気の性質の違う所を通るときに、進む向きを変えること。 |
| 屈折率（index of refraction、n） | 真空中の電波の速さを、その場所での速さで割った値。地表近くの空気では 1.00025〜1.0004。 |
| 屈折度（refractivity、N） | 屈折率 n から 1 を引いて 100 万倍した値。扱いやすい大きさにするための単位（N 単位）。 |
| 修正屈折度（modified refractivity、M） | 屈折度 N に、高さに比例する量を足した値。M が高さとともに減る層があれば、そこがダクトになる。 |
| 標準大気（standard atmosphere） | 気温が高さとともに一定の割合で下がるなどと仮定した、基準の大気。屈折度は 1 km につき 39 ずつ減る。 |
| 等価地球半径（effective earth radius） | 電波の曲がりを考えるかわりに、地球の半径を大きくして、電波をまっすぐ進むものとして扱う考え方。標準大気では実際の約 4/3 倍。 |
| レーダ水平線（radar horizon） | レーダから出た電波が、地球の表面にちょうど接する点。これより先の低い所は、地球の陰になる。 |
| 見通し距離（line-of-sight range） | レーダと目標のあいだを、地球にさえぎられずに電波が届く、いちばん遠い距離。 |
| 回折（diffraction） | 電波が、障害物の陰に少し回り込むこと。周波数が低いほど回り込みやすい。 |
| 反射係数（reflection coefficient） | 反射した波の強さ（電界）を、入ってきた波の強さで割った値。なめらかな海面に浅い角度で入ると、1 に近い。 |
| 直接波と反射波（direct / reflected wave） | レーダと目標のあいだをまっすぐ進む波（直接波）と、海面や地面で一度反射して届く波（反射波）。 |
| ローブ（lobe） | 直接波と反射波が強め合って、電波が強くなる角度の範囲。高さの方向に、ヌルと交互に並ぶ。 |
| カバレッジ図（coverage diagram） | 距離と高度の平面の上に、どこで目標が見えるか（電波の強さや探知確率）を描いた図。 |
| 異常伝搬（anomalous propagation） | 大気が標準の状態と違うために、電波の曲がり方がふつうと違うこと。 |
| サブリフラクション（subrefraction） | 電波がふつうより曲がらない、または上向きに曲がる状態。見通し距離が短くなる。 |
| スーパーリフラクション（superrefraction） | 電波がふつうより強く下向きに曲がる状態。見通し距離が長くなる。 |
| トラッピング（trapping） | 電波の曲がりが地球の丸みより強くなり、電波が大気の層の中に閉じ込められる状態。 |
| ダクト（duct） | 電波が閉じ込められて、遠くまで伝わる大気の層。 |
| 蒸発ダクト（evaporation duct） | 海面のすぐ上で、水蒸気が高さとともに急に減ることでできるダクト。海の上ではほぼいつも存在する。 |
| レーダホール（radar hole） | ダクトのために電波が届きにくくなる領域。ダクトのすぐ上などにできる。 |
| スキップゾーン（skip zone） | 水平線の近くで、ダクトの効果が現れない距離の範囲。 |
