### 3.2 問い・選択肢・正解・ミッション

**ステップ 1　場所ごとに違う背景**

- 問い：丘や建物からのエコー（クラッタ）は、場所によって強さが 1000 倍も違う。全部の場所に、同じ高さのしきい値を使うと？
- 選択肢：A) どの高さにしても、うまくいく場所は一部だけ　**← 正解**　B) 十分に高くすれば、すべての場所でうまくいく　C) 十分に低くすれば、すべての場所でうまくいく
- 理由：しきい値を低くすると、クラッタの強い場所で、クラッタを目標と間違えます（誤警報）。高くすると誤警報は消えますが、クラッタの弱い場所にいる目標まで見逃します。背景の強さが場所ごとに違うのに、しきい値が 1 本しかないことが、問題の元です。
- ミッション：固定のしきい値で、誤警報を 1 スキャンあたり平均 0.5 個以下にする、いちばん低いしきい値を探そう。そのとき、目標は見えているだろうか。
- 達成できる設定の例（検証で使用）：`{"thr": 33}`

**ステップ 2　地図を作る**

- 問い：地図は、スキャンのたびに「前の値に、新しい受信を少しだけ混ぜる」方法で更新する。混ぜる割合 α を小さくすると？
- 選択肢：A) 地図の値は落ち着くが、背景が変わったときに追いつくのが遅くなる　**← 正解**　B) 地図の値がばらつき、背景の変化にもすぐ追いつく　C) 地図の値は落ち着き、背景の変化にもすぐ追いつく
- 理由：α が小さいと、過去のたくさんのスキャンを平均することになるので、地図の値はなめらかになります。そのかわり、背景の強さが変わったとき（雨が降り出した、など）に、新しい強さになじむまでに、多くのスキャンがかかります。落ち着きと素早さは、両立しません。
- ミッション：実効的な平均の回数 Leff が、ちょうど 15 になる α を探そう（ハンドブックの例の値）。
- 達成できる設定の例（検証で使用）：`{"p": 3}`

**ステップ 3　しきい値を決める**

- 問い：地図の値に係数 kT を掛けたものを、しきい値にする。kT を、背景の平均が正確に分かっているときと同じ値にすると、誤警報は？
- 選択肢：A) ねらいより増える（地図の値が、ばらつくから）　**← 正解**　B) ねらいどおりになる　C) ねらいより減る
- 理由：地図の値は、限られた回数の平均なので、本当の平均の上下にばらつきます。たまたま低く出たマスでは、しきい値も低くなり、誤警報が出やすくなります。この分を見込んで、kT を少し大きくしておく必要があります。
- ミッション：誤警報確率が 10⁻⁵ 以下になる、いちばん小さい kT を探そう。
- 達成できる設定の例（検証で使用）：`{"kdb": 12.25}`

**ステップ 4　地図の損失**

- 問い：地図の平均の回数（Leff）を減らすと、同じ目標を、同じ確率で検出するのに必要な S/N は？
- 選択肢：A) 変わらない　B) 大きくなる（感度を損する）　**← 正解**　C) 小さくなる（感度が上がる）
- 理由：平均の回数が少ないと、地図の値のばらつきが大きくなります。誤警報を抑えるには、係数 kT を大きくしなければなりません（ステップ 3）。しきい値が上がるので、同じ確率で検出するには、目標がそのぶん強くなければなりません。この余分に要る S/N が、クラッタマップ損失です。
- ミッション：損失が 1 dB 以下になる、いちばん大きい α を探そう。
- 達成できる設定の例（検証で使用）：`{"p": 4}`

**ステップ 5　立ち上がり**

- 問い：今までなかった場所に、強い点のクラッタが現れた（新しい建物、止まった車など）。クラッタマップは、最初のうち、どう反応する？
- 選択肢：A) 最初から無視できる　B) 永久に目標として検出し続ける　C) しばらくは目標として検出してしまい、スキャンを重ねると無視するようになる　**← 正解**
- 理由：地図は、そのマスを「雑音だけの場所」と覚えています。そこへ強いエコーが現れると、しきい値を大きく超えるので、目標として検出されます。スキャンのたびに、新しい強さが地図に混ざり、しきい値が上がっていきます。何スキャンかすると、「いつもの強さ」として扱われ、検出されなくなります。
- ミッション：10 スキャン目に、検出してしまう確率が 10⁻³ 以下になる、いちばん小さい α を探そう。
- 達成できる設定の例（検証で使用）：`{"p": 3}`

**ステップ 6　遅い目標は消える**

- 問い：ゆっくり動く目標が、何スキャンも同じマスの中にいる。クラッタマップは、この目標をどう扱う？
- 選択肢：A) だんだん背景として覚えてしまい、検出しにくくなる　**← 正解**　B) 動いているので、いつまでも検出できる　C) 遅い目標ほど、よく検出できる
- 理由：クラッタマップは、「同じマスに、いつも見えるもの」を背景とみなします。目標でも、同じマスに何スキャンも居座れば、その強さが地図に混ざり、しきい値が上がります。地図は、クラッタと遅い目標を区別できません。1 スキャンのあいだにマスの外へ出る速さがあれば、覚えられずに済みます。
- ミッション：検出確率が 0.9 を超える、いちばん遅い速さを探そう。
- 達成できる設定の例（検証で使用）：`{"v": 175}`

**ステップ 7　MTD での使い方**

- 問い：目標がレーダの視線を真横に横切ると、ドップラは 0 になる。MTI やドップラフィルタは、クラッタと一緒に、この目標も消してしまう。クラッタマップを使うと？
- 選択肢：A) クラッタの強い場所でも、必ず検出できる　B) クラッタのない（弱い）場所なら、検出できる　**← 正解**　C) どこにいても、検出できない
- 理由：ドップラ 0 の成分だけを取り出す通り道（ゼロ速度フィルタ）を別に用意し、その出力をクラッタマップのしきい値で判定します。クラッタの弱い場所では、しきい値が低いので、横切る目標が検出できます。クラッタの強い場所では、しきい値が高く、目標がクラッタより十分強くないと検出できません。
- ミッション：横切る目標（ゼロ速度のチャネル）の検出確率が 0.5 以上になる、いちばん強いクラッタを探そう。
- 達成できる設定の例（検証で使用）：`{"cdb": 11}`

**ステップ 8　自由実験とまとめ**

- 問い：クラッタマップが、うまく働きにくいのは、どんなレーダ？
- 選択肢：A) 地上に据え付けられ、同じ周波数で送信するレーダ　B) アンテナが回転しているレーダ　C) 自分が動いているレーダや、送信の周波数をパルスごとに変えるレーダ　**← 正解**
- 理由：クラッタマップは、「同じマスの受信は、スキャンが変わっても同じ強さ」であることに頼っています。レーダが動くと、同じマスに入る地面が変わります。周波数を変えると、同じ地面でも、エコーの強さが変わります。どちらも、地図の値が、今の背景を表さなくなります。ハンドブックも、クラッタマップは、止まっていて、同じ周波数で動くレーダでよく働く、と述べています。
- ミッション：損失が 1.5 dB 以下で、しかも、10 スキャン目に新しいクラッタを検出してしまう確率が 10⁻³ 以下になる設定を作ろう。
- 達成できる設定の例（検証で使用）：`{"n": 4, "p": 2}`

### 3.4 このシミュレータで決めたこと

- **確率は式で計算しています**（乱数の試行ではありません）。受信の強さを、セルごと・スキャンごとに独立な指数分布とし、地図の値が「指数分布の重み付きの和」になることを使っています。この式はハンドブックにはなく、補足です。誤警報確率 10⁻³ の場合を、40 万回の乱数の試行で確かめています（照合表の最後の行）。
- **損失の定義**：検出確率 0.5 で、背景の平均が正確に分かっている場合と比べた S/N の差としました。
- **速度の応答（ステップ 6）**：マップセル（分解能のセル 5 つ）と前後 1 セルの、合わせて 7 セルの中で、いちばん強い受信で地図を更新するとしました。ほかの案（7 セルを平均する、1 つずつ順に混ぜる）も試しましたが、止まっている点のクラッタが抑えられなかったり、図2.92 と大きく違ったりしたので、この案にしています。
- **MTD での使い方（ステップ 7）**：2 つのチャネルを、平均の強さだけで比べる簡略モデルです。クラッタの減衰 40 dB、目標の S/N 25 dB は説明用の値です。MTD の具体的な構成（フィルタの数など）や、例として本文に出てくる装置の名前は、扱っていません。
- **ステップ 1 の場面**（方位 120 本 × 距離 100 セル。丘、尾根、建物、鉄塔、町、目標 A・B）は、説明用に作ったものです。クラッタマップを PPI に重ねた絵（色がマスごとの地図の値、× が固定のしきい値を超えたマス）と、その中の 1 つの方位を切り出した図を、上下に並べています。PPI に重ねる見せ方は理解のための絵で、ハンドブックにこの表示の説明があるわけではありません。

### 3.5 「補足」として入れた説明

### 3.6 新人がつまずきやすい誤解（各ステップの「④よくある誤解」）

| # | ステップ | よくある誤解と、その直し方 |
|---|---|---|
| 1 | 場所ごとに違う背景 | 「クラッタマップは、クラッタを消す」わけではありません。クラッタはそのまま残っていて、しきい値のほうを、場所ごとに持ち上げているだけです。クラッタより弱い目標は、そのセルでは見えません。クラッタそのものを弱めるのは、MTI やドップラ処理の役目です（第2回、第3回）。 |
| 2 | 地図を作る | 「α は小さいほど良い」とは限りません。小さいと、背景の変化や、新しく現れたクラッタに慣れるのが遅れます（ステップ 5）。また、ゆっくり動く物を背景として取り込みにくくなります。大きすぎると、地図がばらついて、感度を損します（ステップ 4）。 |
| 3 | しきい値を決める | 「kT は、誤警報確率だけで決まる」わけではありません。地図の平均の回数（α）でも変わります。α を変えたら、kT も決め直します。また、kT を dB で足すのは、地図の値に倍率を掛けることです。 |
| 4 | 地図の損失 | 「この曲線の損失が、そのまま実際のレーダの損失になる」とは限りません。曲線は、1 回の受信で判定する場合のものです。ハンドブックも、多くのレーダは何回かの受信を積分してから判定するので、この値では大きすぎることがある、と注意しています（自由実験で確かめられます）。 |
| 5 | 立ち上がり | 「クラッタマップがあれば、クラッタの誤警報は出ない」わけではありません。出なくなるのは、地図が慣れたあとです。電源を入れた直後、背景が急に変わったとき、クラッタがマスの境目をまたいで動いたときには、しばらく誤警報が出ます。 |
| 6 | 遅い目標は消える | 「クラッタマップは、止まっている物だけを抑える」わけではありません。マスの大きさとスキャンの間隔で決まる速さより遅い物は、動いていても抑えられます。鳥の群れを抑えたいときには都合がよく、遅い航空機を見たいときには困ります。 |
| 7 | MTD での使い方 | 「強い目標は、クラッタの上でも必ず見える」わけではありません。ゼロ速度のチャネルでは、目標が、そのマスのクラッタより十分に強くなければなりません。ハンドブックは、強い目標が点のクラッタの上を飛ぶときに検出できることを、スーパークラッタビジビリティと呼んでいます。 |
| 8 | 自由実験 | このシミュレータは、1 つのマスの統計だけを扱っています。実際の地図は何十万ものマスを持ち、マスの大きさ、広げ方、更新のしかたに、いろいろな作り方があります。また、地図を更新するには、その場所を繰り返し見る必要があります。ビームを自由に振るレーダでは、そのための時間を捜索や追尾と分け合います（第13回）。 |

## 5. 追加した用語（13 語。全回共通の用語集は 267 語になった）

| 用語（日本語／英語） | 説明 |
|---|---|
| エリア MTI（area MTI） | クラッタの消え残りを場所ごとに記憶しておき、次のスキャンで差し引く（または割る）方法。今はクラッタマップと呼ぶことが多い。 |
| マップセル（map cell） | クラッタマップの 1 マス。距離と方位で区切る。分解能のセルいくつかをまとめて 1 マスにすることが多い。 |
| 再帰フィルタ（recursive filter） | 前の出力に、新しい入力を一定の割合で混ぜて、次の出力にするフィルタ。過去の値を全部しまっておかなくても、平均に近い値が得られる。 |
| フィルタの定数 α | 再帰フィルタで、新しい入力を混ぜる割合（0〜1）。小さいほど、長い期間の平均になる。 |
| 実効的な平均の回数（Leff） | 再帰フィルタが、同じ重みで何回ぶんを平均したのと同じ落ち着きを持つかを表す数。(2 − α) ÷ α。 |
| クラッタマップ損失（clutter map loss） | 背景の平均を地図から見積もるために、余分に必要になる S/N。平均の回数が少ないほど大きい。 |
| 立ち上がり（過渡応答、transient response） | 背景が急に変わったとき（新しいクラッタが現れたときなど）に、地図の値が新しい強さになじむまでの様子。 |
| カットオフ速度（cutoff velocity） | クラッタマップが目標を背景として覚えはじめる、目標の速さの境目。マップセルの大きさとスキャンの間隔で決まる。 |
| スプレッディング（spreading） | マップセルを、その中の受信だけでなく、隣のセルの受信も使って更新すること。クラッタがマスの境目をまたいだときの誤警報を抑える。 |
| ゼロ速度フィルタ（zero-velocity filter） | ドップラが 0 に近い成分だけを取り出すフィルタ。止まっているクラッタと、視線を横切る目標が、ここに出る。 |
| MTD（moving target detector） | ドップラフィルタバンク、ゼロ速度フィルタ、クラッタマップなどを組み合わせた、目標検出の方式。 |
| スーパークラッタビジビリティ（superclutter visibility） | 点のクラッタの上を飛ぶ目標を、目標のほうがクラッタより強いことを利用して検出できること。 |
| 点のクラッタ（discrete clutter / point clutter） | 建物や鉄塔のように、1 つのセルに集中して現れる強いクラッタ。 |

「クラッタマップ（clutter map）」そのものは、第2回の用語をそのまま使っています。
