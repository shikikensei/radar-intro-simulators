## もとにする資料

Radar Handbook 第3版 第1章 §1.4 The Radar Equation（p.1.10–1.13）。**この範囲で足りる。** 資料の PDF はリポジトリに入っていないので、必要な式と記述を下に書く（言い換え）。ここにないことを書くときは「補足」にする。

**式1.2（p.1.11）受信電力**
`Pr = Pt·Gt / (4πR²) × σ / (4πR²) × Ae`

**式1.3（p.1.11）最大探知距離**
`Rmax⁴ = Pt·Gt·Ae·σ / ( (4π)²·Smin )`

**式1.4（p.1.11）最小検出信号**
`Smin = k·T0·B·Fn·(S/N)1`
- `k·T0`：理想的な抵抗の熱雑音。T0 = 290 K で、`k·T0 = 4×10⁻²¹ W/Hz`。
- `B`：受信機の帯域幅。`Fn`：雑音指数（実際の受信機の雑音 ÷ 理想の受信機の雑音）。
- `(S/N)1`：パルスが 1 つだけのときに、検出に要る S/N。誤警報確率と検出確率から決まる（値の求め方は、この章には書かれていない）。

**式1.5（p.1.12）ふつうの形**
`Rmax⁴ = Pav·G·Ae·σ·n·Ei(n)·F⁴ / ( (4π)²·k·T0·Fn·fp·(S/N)1·Ls )`
- レーダは、ふつう何個かのパルスを足し合わせて（積分して）から判定する。そのぶん、分子に `n·Ei(n)` が掛かる。`n`：パルスの数。`Ei(n)`：n 個を足し合わせる効率（値の求め方は、この章には書かれていない）。
- 尖頭電力 Pt より、平均電力 `Pav` のほうが、探知能力をよく表す。`Pt = Pav / (fp·τ)`（fp：パルス繰り返し周波数、τ：パルス幅）。
- 地面や大気の影響は、伝搬因子 `F⁴` で表す（第26章。この教材では第9回）。
- 導くときに `B·τ ≈ 1` と仮定している。
- `Ls`：システム損失（1 より大きい）。**すべての損失を数えると 10〜20 dB になることも珍しくない。** 無視すると、距離の見積もりを大きく誤る。
- この式は、目標を時間 `t0 = n / fp` のあいだ見続ける場合（たとえば追尾レーダ）のもの。

**式1.6（p.1.12）捜索レーダの形**
`Rmax⁴ = Pav·Ae·σ·Ei(n)·F⁴·ts / ( 4π·k·T0·Fn·(S/N)1·Ls·Ω )`
- 捜索レーダは、立体角 `Ω` を、再訪時間 `ts` のうちに見て回る。`ts = t0·(Ω / Ω0)`、`G = 4π / Ω0`（Ω0：ビームの立体角）。これを式1.5 に入れると得られる。
- 航空管制のレーダでは、再訪時間は 4〜12 秒ほど。
- `ts` と `Ω` は、レーダの役目でほぼ決まる。目標の大きさもそう。だから、遠くまで見るには `Pav·Ae`（電力開口積）が要る。
- **この式には、周波数があらわには出てこない。**

**そのほかの記述（p.1.12–1.13）**
- 用途ごとに、合った形の方程式を使う。
- クラッタが雑音より強い場所では、雑音ではなくクラッタで探知が決まり、別の形の式が要る。妨害を受けているときも同じ（式は示されていない）。

## ステップの案（8 ステップ）

各ステップで動かす値は 1 つ。最後が自由実験。案なので、作りながら直してよい（直したら報告する）。

| # | 題（案） | 動かす値 | 伝えたいこと | 式 |
|---|---|---|---|---|
| 1 | 4 乗根の重さ | 送信電力 | 距離を 2 倍にするには、電力が 16 倍要る | 1.3 |
| 2 | アンテナは 2 回効く | アンテナの大きさ（または利得） | 送るときと受けるときの両方に効く。利得・開口・波長の関係 | 1.2、1.3 |
| 3 | 受信機の雑音 | 雑音指数（帯域幅は固定で表示） | 最小検出信号は雑音で決まる。k·T0 = 4×10⁻²¹ W/Hz | 1.4 |
| 4 | 検出に要る S/N | (S/N)1 | 確実に見つけたいほど、強い信号が要る（決め方は第4回へ） | 1.4 |
| 5 | パルスを足し合わせる | パルスの数 n | 積分で、同じ電力でも遠くまで見える。効率 Ei(n) | 1.5 |
| 6 | 尖頭電力より平均電力 | パルス幅（またはデューティ） | 効くのは平均電力。尖頭電力が同じでも、長いパルスなら遠くまで | 1.5 |
| 7 | 損失を忘れない | システム損失 Ls | 10〜20 dB の損失で、距離は 0.56〜0.32 倍になる | 1.5 |
| 8 | 捜索レーダの形 | 再訪時間（または見る範囲） | 電力開口積。周波数があらわに出てこない | 1.6 |
| 9 | 自由実験とまとめ | 全部 | 伝搬因子 F も含めて、すべての変数を動かす | 1.5、1.6 |

（9 ステップになってもよい。8 に収めるなら、3 と 4 を「最小検出信号」として 1 つにする。）

自由実験では、**式1.5 に出てくる変数をすべて**操作できるようにする：Pav（または Pt と τ と fp）、G（または Ae と周波数）、σ、n、Ei、F、Fn、(S/N)1、Ls。操作部が多くなるので、まとまり（送信・アンテナ・目標・受信・損失）ごとに並べる。

## 気をつけること

- **Ei(n) と (S/N)1 の求め方は、資料にない。** モデルを置くなら「補足」にして、何を仮定したかを書く（例：位相をそろえて足せば Ei = 1、そろえずに足すと 1 より小さい）。(S/N)1 は、値を与えるだけにして、決め方は第4回へのリンクで済ませてよい。
- **クラッタや妨害で決まる場合の式は、資料に示されていない。** 触れるのは「別の形が要る」ことと、関係する回（第2回、第12回、第14回）へのリンクまで。
- 第0回の計算（`c0_core.js` の `prOf`、`sminOf`、`rmaxOf`）と同じ結果になること。第0回のステップは変えない（リンクの追記は可）。
- 数値はすべて説明用。実在の装置の値を使わない。
- 問いの正解の位置を散らす。

## 照合に使える値

- `k·T0 = 4×10⁻²¹ W/Hz`（T0 = 290 K）
- 電力 16 倍で、距離 2 倍
- 損失 10 dB で距離 0.56 倍、20 dB で 0.32 倍（10 の −Ls/40 乗）
- 式1.5 に `n / fp = 4π·ts / (G·Ω)` を入れると、式1.6 と同じ値になること
- 式1.6 では、Pav・Ae・ts・Ω を固定して周波数を変えても、距離が変わらないこと
- 第0回の最大探知距離と、同じ条件で一致すること
